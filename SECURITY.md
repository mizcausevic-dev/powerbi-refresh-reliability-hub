# Security Policy

## Data posture

- This repo only ships synthetic Power BI refresh, gateway, semantic-model, and report-delivery samples.
- Do not commit live tenant identifiers, refresh histories, workspace membership exports, gateway secrets, or embedded credentials.

## Reporting concerns

- This project demonstrates operator posture and remediation sequencing, not Microsoft compliance certification.
- Never describe the repo or the live surface as guaranteeing security, regulatory compliance, or tenant-hardening outcomes.

## Responsible disclosure

If you find a vulnerability in this repo, open a private security advisory or email the maintainer before public disclosure.
